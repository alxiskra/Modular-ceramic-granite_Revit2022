# Дополнительный контекст

ГОСТ 13996-2019:<br>
3.13 Номинальный размер N: Размер для обозначения изделия.<br>
3.14 Фактический размер P: Размер, получаемый измерением поверхности керамической плитки.<br>
3.15 Рабочий размер W (калибр): Размер, устанавливаемый для процесса изготовления керамических плиток, которому должен соответствовать фактический размер в пределах допустимых отклонений для заданного калибра. Данный размер включает длину, ширину и толщину.<br>
3.16 Координационный размер C: Рабочий размер, включающий ширину шва.<br>
3.1 Керамические плитки: Тонкостенные изделия, изготовляемые методом экструзии (метод А) или методом полусухого прессования (метод В) на основе глинистых и/или других неорганических материалов с последующей сушкой и обжигом изделий при температуре, необходимой для достижения требуемых показателей.<br>
4.1 Керамические плитки подразделяют на три группы по показателю "водопоглощение".<br>
3.5 Керамический гранит (керамогранит): Керамическая плитка с водопоглощением не более 0,5%
Пример определения из документации крамогранита Estima:<br>
Керамический гранит – разновидность керамической плитки, получаемой прессованием и имеющей водопоглощение 0,5% - самое низкое для всех напольных и настенных плиток.

В зоне укладки керамогранита рекомендуется предусматривать деформационные швы, совпадающие с температурно-усадочными швами стяжки, с шагом не более 6 м, с заполнением эластичным полиуретановым герметиком по жгуту из вспененного пенополиэтилена (п.8.14, СП29.13330.2011);.<br>
По всему периметру примыкания покрытия к стенам, колоннам, внутрипольным конвекторам рекомендуется предусматривать деформационные швы шириной 6–10мм на всю толщину конструкции пола, совпадающие с изолирующими швами стяжки (Табл.8.2, СП71.13330.2017) с прокладкой демпферной ленты и герметизацией примыкания эластичным полиуретановым герметикам по уплотнительному шнуру.
